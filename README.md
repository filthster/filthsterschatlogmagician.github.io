# FILTHLINES CHATLOG EDITOR

GitHub Pages setup:
1. Extract this ZIP.
2. Upload index.html, app.js, style.css, filthlines-icon.png and .nojekyll to the ROOT of your public GitHub repository. Upload the files, not the ZIP or its containing folder.
3. Open Settings > Pages > Deploy from a branch.
4. Select main and / (root), then Save.

For https://YOURUSERNAME.github.io, name the repository YOURUSERNAME.github.io.
For a project URL, use any repository name (e.g. filthlines-chatlog-editor).

No build step or paid hosting is required.
Use Save Project on the old editor and Open Project on the new site to transfer your work.
